## Scenario traces

### WRONG STATE

Chose **Y attempt before transition completion** after a valid X → cause → Y-prep. Cleaner for W4 than “Y with no schedule”: the schedule and preparation are already correct; only current World State is wrong.

```
SOLID use X: supported=true
activate ACK elapsed=16.7ms phase=PENDING state=SOLID
prepare Y during PENDING
Y attempt 516.7ms at 248.0,450.0 state=SOLID traversed=false ready=READY AT SETTLE
```

X still available (SOLID). Cause timing after X. Player is in the Y approach slab. Y is blocked only because current state is still SOLID. ~203ms of pending remain — not a 2-frame miss.

### WRONG TIMING

EXP-002 early-activation seam.

```

Y from staging after settle traversed=true

```

Y is available. Combined goal fails because unused X is gone. Missing Y-prep is not the cause.

### WRONG PREPARATION


State is correct. Cause timing is valid. Player stayed at the activator. Failure is unreadiness, not expiry.

## Orthogonality

- WRONG STATE is not timing: X was used; cause was after X; X is still available.
- WRONG TIMING is not missing prep: Y from staging after settle succeeds.
- WRONG PREPARATION is not wrong state or early cause: observation is PASSABLE after a post-X cause.

Classification uses `diagnoseFromFacts`, not the scripted scenario name.

---

## False positives

- WRONG STATE is not a movement miss: the same Y attempt from 248,450 / 260,450 succeeds once PASSABLE. Only current SOLID blocks it.
- WRONG TIMING is not geometry-forced order: activate-first and X-first remain open (EXP-002).
- WRONG PREPARATION is not “slower but ready”: wait pose is NOT READY, 33 frames / 152px short of staging.
- Overlap-refuse count = 0 on all four traces.
- No new mechanic, no hidden timer, no exact-frame window.
