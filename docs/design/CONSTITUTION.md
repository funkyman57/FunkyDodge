# FunkyDodge Constitution v0.1

Highest-level design authority.

If a library entry, level, gimmick, or implementation conflicts with this document, this document wins.

---

## Eight principles

### C-01 — The Rules Never Lie

Under identical relevant conditions, rules produce consistent results.

Never secretly change a rule because a particular level needs it.

### C-02 — Thinking > Execution

The difficulty should primarily come from discovering the solution.

Once the solution is understood, execution should feel achievable rather than becoming a second major test.

### C-03 — Simple Controls, Deep Possibilities

Keep player input simple.

Depth should emerge from physics, timing, rule interaction, and player understanding rather than additional buttons.

### C-04 — Bounce Is Identity

Automatic bouncing is a fundamental identity of FunkyDodge.

Do not gradually turn the game into a conventional platformer with a normal jump button.

### C-05 — Depth Over Quantity

Before introducing a new gimmick:

1. Try a new application of an existing rule.
2. Try a new combination of existing rules.
3. Try a meaningful variation of an existing rule.
4. Only then consider a new gimmick.

New gimmicks are the last resort.

### C-06 — Surprise Comes From Possibility

Surprise must come from discovering an unexpected possibility within known rules.

Never rely on hidden information or arbitrary rule changes for surprise.

### C-07 — Every Gimmick Has Another Face

Important gimmicks should support at least two meaningful uses.

A gimmick should not exist only to perform one predetermined action.

### C-08 — Every Room Has a Purpose

Every room must do at least one of:

- Teach
- Apply/Test
- Surprise
- Reward

A room without a clear purpose should not exist.
